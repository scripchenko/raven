# Безопасность и конфиденциальность

## Принципы

raven показывает официальные веб-приложения и не реализует чужие протоколы. Приложение не должно перехватывать пароли, коды подтверждения, QR-коды, cookies, сообщения, контакты или введённый пользователем текст.

## Навигация

Для каждого сервиса каталог содержит разрешённые домены. Политика принимает только абсолютные HTTPS-адреса с точным разрешённым доменом или его настоящим поддоменом и защищена от совпадений вида `web.telegram.org.evil.example`. Для `id.vk.ru` сохранён режим `ExactOnly`: его поддомены не разрешаются. Внешние адреса передаются браузеру Windows по умолчанию. TLS, проверка сертификатов и web security не отключаются.

Эта же политика проверяет origin запросов разрешения и web-уведомлений. Внешний или неизвестный origin не получает разрешение и не создаёт desktop-уведомление. Решение `Allowed`/`Denied` хранится отдельно для каждого `ServiceInstance` и сохраняется WebView2 в его стабильном профиле; запросы камеры, микрофона, геолокации и других разрешений на этом этапе не перехватываются.

## Профили WebView2

Используется общая папка `%LOCALAPPDATA%\UnifiedMessenger\WebView2` и отдельный профиль `service-{guid}` для каждого аккаунта Telegram, WhatsApp, MAX или VK. `CreationProperties` задаются до инициализации контрола, приватный режим выключен, поэтому стандартные cookies и локальное хранилище сохраняют авторизацию между запусками. Они не копируются, не сериализуются и не читаются приложением.

При удалении аккаунта менеджер закрывает только его WebView2, очищает данные его профиля и удаляет только проверенный каталог с тем же `ProfileName`. Если каталог занят, имя профиля сохраняется в очереди повторной очистки. Очередь игнорирует и снимает записи для профилей, которые всё ещё принадлежат существующим аккаунтам.

## Настройки и секреты

Обычные настройки хранятся в `%APPDATA%\UnifiedMessenger\settings.json`. Этот файл не предназначен для паролей и токенов. OAuth-credentials, токены и локальные token-файлы исключены через `.gitignore`. Gmail refresh token на этапе 7 должен шифроваться Windows DPAPI для текущего пользователя.

Встроенный экран настроек не показывает абсолютные пути, GUID, `ProfileName`, cookies или параметры авторизации. Изменение настроек переиспользует атомарное JSON-хранилище и существующий lifecycle аккаунтов; открытие Settings не очищает и не пересоздаёт WebView2-профили.

## Журналы

Будущие структурированные журналы смогут содержать тип и идентификатор сервиса, версии, времена запуска и технические коды ошибок. Запрещены пароли, коды, QR, cookies, токены, тексты сообщений и писем, адресаты, темы писем и URL-параметры с секретами.

## Уведомления и активность

Приложение использует только `DocumentTitleChanged`, безопасный начальный счётчик и типизированное `NotificationReceived`. Оно не анализирует DOM и не внедряет JavaScript. Исходные `Title` и `Body` web-уведомления передаются только в оперативную popup-модель при разрешённом preview, не входят в диагностику и не записываются на диск; очередь существует только в памяти и содержит не более 20 ожидающих элементов.

Индикаторы аккаунта, taskbar overlay и tooltip содержат только количество или общий факт новых событий. DND и mute подавляют popup до передачи содержимого в UI без изменения web-разрешения, профиля или cookies. После подавления, очистки очереди либо выхода уведомление безопасно завершается и не показывается позднее.
