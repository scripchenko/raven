# Безопасность и конфиденциальность

## Принципы

UnifiedMessenger показывает официальные веб-приложения и не реализует чужие протоколы. Приложение не должно перехватывать пароли, коды подтверждения, QR-коды, cookies, сообщения, контакты или введённый пользователем текст.

## Навигация

Для каждого сервиса каталог содержит разрешённые домены. Политика принимает только абсолютные HTTPS-адреса с точным разрешённым доменом или его поддоменом и защищена от совпадений вида `web.telegram.org.evil.example`. Внешние адреса на следующих этапах будут передаваться браузеру Windows по умолчанию. TLS, проверка сертификатов и web security не отключаются.

## Профили WebView2

Используется общая папка `%LOCALAPPDATA%\UnifiedMessenger\WebView2` и отдельный профиль `service-{guid}` для Telegram. `CreationProperties` задаются до инициализации контрола, приватный режим выключен, поэтому стандартные cookies и локальное хранилище сохраняют авторизацию между запусками. Они не копируются, не сериализуются и не читаются приложением.

## Настройки и секреты

Обычные настройки хранятся в `%APPDATA%\UnifiedMessenger\settings.json`. Этот файл не предназначен для паролей и токенов. OAuth-credentials, токены и локальные token-файлы исключены через `.gitignore`. Gmail refresh token на этапе 7 должен шифроваться Windows DPAPI для текущего пользователя.

## Журналы

Будущие структурированные журналы смогут содержать тип и идентификатор сервиса, версии, времена запуска и технические коды ошибок. Запрещены пароли, коды, QR, cookies, токены, тексты сообщений и писем, адресаты, темы писем и URL-параметры с секретами.
