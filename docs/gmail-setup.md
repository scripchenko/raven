# Настройка Gmail API (для этапа 7)

Gmail-модуль ещё не реализован. Эта инструкция фиксирует безопасную схему будущего подключения. Авторизация Google не будет выполняться внутри WebView2.

1. Создайте отдельный проект в Google Cloud Console.
2. В разделе API Library включите Gmail API.
3. Настройте OAuth consent screen, укажите название приложения и необходимые контактные данные.
4. Создайте OAuth client типа **Desktop application**. Не создавайте Web application client для локального WPF-приложения.
5. Пока consent screen находится в тестовом режиме, добавьте нужный Google-аккаунт в список тестовых пользователей.
6. Скачайте credentials и сохраните локально под ожидаемым приложением именем `credentials.json`. За основу структуры можно взять корневой `credentials.example.json`. Настоящий файл нельзя коммитить.
7. После реализации этапа 7 запустите подключение аккаунта. UnifiedMessenger откроет системный браузер и примет redirect только на loopback-адресе `127.0.0.1` со случайным свободным портом.
8. Чтобы отозвать доступ, удалите разрешение UnifiedMessenger в настройках безопасности Google-аккаунта и удалите локальную учётную запись из приложения.

Будет запрашиваться минимальный Gmail OAuth scope, необходимый для списка и чтения писем и изменения признака прочитанности. Отправка писем и ответы потребуют отдельного последующего этапа и дополнительного согласия. Токены будут храниться в `%LOCALAPPDATA%\UnifiedMessenger\Gmail\Accounts\<account-id>\` и защищаться Windows DPAPI.
